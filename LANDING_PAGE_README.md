# CyberSecure Landing Page

A professional, cybersecurity-themed landing page for the Flask password manager with modern animations, responsive design, and compelling user experience.

## 🎨 Design Features

### Cybersecurity Theme
- **Dark color palette**: Deep blacks, blues, and cyans for a professional security aesthetic
- **Gradient accents**: Subtle gradients using cyber-blue and cyber-purple
- **Glowing effects**: CSS shadows and animations for a futuristic feel
- **Typography**: Inter font for body text, JetBrains Mono for technical elements

### Modern UI Components
- **Fixed navigation**: Smooth scroll navigation with active link highlighting
- **Hero section**: Compelling headline with animated statistics and call-to-action buttons
- **Feature grid**: Six key features presented in an attractive card layout
- **Security visualization**: Layered diagram showing security architecture
- **Call-to-action section**: Final conversion section with trust indicators
- **Professional footer**: Comprehensive footer with links and badges

## 🚀 Animations & Interactions

### Scroll Animations
- **Fade-in effects**: Elements animate into view as user scrolls
- **Staggered animations**: Feature cards and security items animate sequentially
- **Intersection Observer**: Performance-optimized scroll detection

### Hero Animations
- **Floating elements**: Security icons float around the central shield
- **Rotating shield**: Animated security shield with glowing effects
- **Counter animations**: Statistics count up from zero
- **Particle effects**: Subtle background particles for atmosphere

### Interactive Elements
- **Hover effects**: Buttons and cards respond to mouse interaction
- **Mobile menu**: Hamburger menu for mobile navigation
- **Smooth scrolling**: Anchor links scroll smoothly to sections
- **Loading animation**: Page fades in on load

## 🎨 Customization

### Color Scheme
The landing page uses a comprehensive color system defined in CSS custom properties:

```css
--cyber-dark: #0a0a0a;      /* Primary background */
--cyber-blue: #00d4ff;      /* Primary accent */
--cyber-cyan: #00ff88;      /* Secondary accent */
--cyber-purple: #8b5cf6;     /* Tertiary accent */
--cyber-gray-900: #111827;  /* Surface colors */
```

### Typography
